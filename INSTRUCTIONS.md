# Пошаговая инструкция по запуску проекта

Личный чек-лист: от создания базы в Supabase до рабочей ссылки на Vercel.
Всего это займёт 15-20 минут.

---

## Шаг 1. Создать проект в Supabase

1. Зайти на [supabase.com](https://supabase.com/) и зарегистрироваться (можно через GitHub).
2. Нажать **New Project**.
3. Заполнить:
   - **Name**: `proptech-ai-portal` (или любое своё)
   - **Database Password**: сгенерировать и сохранить в надёжном месте (пароль не понадобится в коде, но пусть будет записан)
   - **Region**: `Central EU (Frankfurt)` — ближе всего к Праге
4. Нажать **Create new project** и подождать 1-2 минуты, пока Supabase поднимет инфраструктуру.

---

## Шаг 2. Выполнить schema.sql

1. В левом меню открыть **SQL Editor**.
2. Нажать **New query**.
3. Открыть файл `schema.sql` из этого проекта, скопировать **весь** его текст.
4. Вставить в редактор и нажать **Run** (или Ctrl+Enter).
5. Убедиться, что внизу написано `Success. No rows returned` — это значит, что таблица создана, RLS включён и 10 объектов вставлены.
6. Проверить данные: в левом меню открыть **Table Editor → properties** — там должно быть 10 строк.

---

## Шаг 3. Получить ключи API

1. В левом меню открыть **Project Settings → API** (иконка шестерёнки внизу слева).
2. Скопировать два значения:
   - **Project URL** — например `https://xxxxxxxxxxxx.supabase.co`
   - **Project API keys → anon public** — длинная строка вида `eyJhbGciOi...`
3. **Важно:** используем именно `anon public` ключ, а не `service_role`. `service_role` даёт полный доступ на запись и никогда не должен попадать в браузерный код.

---

## Шаг 4. Вставить ключи в config.js

1. Открыть файл `config.js` в этом проекте.
2. Заменить:
   ```js
   const SUPABASE_URL = "https://YOUR-PROJECT-REF.supabase.co";
   const SUPABASE_ANON_KEY = "YOUR-ANON-PUBLIC-KEY";
   ```
   на свои реальные значения из Шага 3.
3. Сохранить файл.

---

## Шаг 5. Проверить локально

Вариант A — если установлен Python:
```bash
cd A:\PropTech
python -m http.server 5500
```
Открыть в браузере: `http://localhost:5500`

Вариант B — если установлен Node.js:
```bash
cd A:\PropTech
npx serve .
```

**Что должно произойти:** слева/сверху загрузится тёмная карта Праги с 10 цветными маркерами (зелёный = хорошая цена, жёлтый = средняя, красный = выше рынка), справа/снизу — список карточек с AI-анализом на чешском. Клик по карточке центрирует карту на объекте, фильтры по району/бюджету/поиску работают мгновенно.

Если вместо карточек ошибка — почти наверняка неправильно вставлены `SUPABASE_URL`/`SUPABASE_ANON_KEY` в `config.js`, либо не был выполнен `schema.sql`.

## Шаг 6. Залить проект на GitHub

1. Зайти на [github.com](https://github.com/) → **New repository**.
   - Name: `proptech-ai-portal`
   - Оставить **Public** (для портфолио это плюс — работодатель сможет сразу открыть код)
   - Не добавлять README/gitignore/license через веб-интерфейс (они уже есть в проекте)
2. В терминале, находясь в папке `A:\PropTech`:
   ```bash
   git init
   git add schema.sql index.html config.js README.md INSTRUCTIONS.md
   git commit -m "Initial commit: PropTech AI Analytics Portal"
   git branch -M main
   git remote add origin https://github.com/<твой-username>/proptech-ai-portal.git
   git push -u origin main
   ```
3. Обновить в `README.md` ссылку `Repository:` на реальный адрес репозитория (необязательно, но красиво для портфолио).

---

## Шаг 7. Задеплоить на Vercel

1. Зайти на [vercel.com](https://vercel.com/) и войти через GitHub.
2. Нажать **Add New → Project**.
3. Выбрать репозиторий `proptech-ai-portal` из списка.
4. Framework Preset — Vercel определит его как **Other** (статический сайт), никаких настроек сборки менять не нужно (Build Command и Output Directory можно оставить пустыми).
5. Нажать **Deploy**.
6. Через 20-30 секунд получишь рабочую ссылку вида `https://proptech-ai-portal.vercel.app`.

**Важный момент:** `config.js` со значениями `SUPABASE_URL`/`SUPABASE_ANON_KEY` уже закоммичен в репозиторий и задеплоится вместе с проектом — это нормально и безопасно, поскольку это публичный (`anon`) ключ, а не секретный. Доступ на запись всё равно заблокирован политикой RLS в базе.

7. После деплоя обновить в `README.md` строку `Live demo:` на полученную ссылку, закоммитить и запушить:
   ```bash
   git add README.md
   git commit -m "Add live demo link"
   git push
   ```
   Vercel автоматически передеплоит проект при каждом пуше в `main` — это и есть CI/CD из требований к вакансии.
